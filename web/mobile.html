📱 Mobile Embed & Config Options

The mobile widget (<ayc-tide-mobile>) is built for phones, sidebars, and narrow portals. It supports easy HTML attributes and JavaScript initialization:

<!-- 1. Include Mobile Component Script --> <script src="https://mlangdon.github.io/ayc-tide-clock/web/ayc-tide-mobile.js" defer></script> <!-- 2. Embed with Custom Options --> <ayc-tide-mobile show-dial="true" dial-size="250" show-weather="true" show-bridges="true" show-table="true" tide-count="4"> </ayc-tide-mobile>

Configuration Attributes:

  • compact="true": Automatically hides dial & forecast for minimal card view.
  • show-dial="false": Hides analog dial, displays compact status pill.
  • dial-size="240": Custom pixel diameter for dial canvas (default 250).
  • tide-count="4": Number of upcoming high/low predictions (default 4 or 6).
  • show-bridges="false": Hides bridge clearance & current tiles.
  • show-weather="false": Hides Tempest weather station observations.
