Web Embedding Instructions

The AYC Tide Clock & Harbor Weather widget is built as a zero-dependency, self-contained Web Component with Shadow DOM encapsulation. This ensures full visual consistency and prevents the host website's CSS styles (WordPress, Squarespace, Wix, ClubExpress, or custom portals) from interfering with the widget.

Method 1: Custom Web Component (Recommended)

Include the script from your public GitHub Pages URL and place the custom tag <ayc-tide-clock> anywhere inside your webpage:

<!-- 1. Load the Atlantis Yacht Club Tide Clock Component --> <script src="https://mlangdon.github.io/ayc-tide-clock/web/ayc-tide-clock.js" defer></script> <!-- 2. Insert the widget tag wherever you want it to appear --> <ayc-tide-clock></ayc-tide-clock>

Method 2: Responsive Iframe Embed

If your website management system or club portal restricts third-party custom JavaScript, you can embed the entire live app seamlessly inside an iframe:

<iframe src="https://mlangdon.github.io/ayc-tide-clock/web/index.html" width="100%" height="780" frameborder="0" style="border: none; border-radius: 8px; max-width: 980px; display: block; margin: 0 auto;" scrolling="no"> </iframe>

Method 3: Dynamic JavaScript Initialization

For single-page applications (React, Vue, Angular, or standard script containers):

<div id="my-tide-container"></div> <script src="https://mlangdon.github.io/ayc-tide-clock/web/ayc-tide-clock.js"></script> <script> window.addEventListener('DOMContentLoaded', () => { window.AYCTideClock.init('#my-tide-container'); }); </script>

Method 4: Mobile-Friendly App Component (<ayc-tide-mobile>) & Config Options

For phones, narrow sidebars, or compact mobile views (320px–480px), use the dedicated mobile component:

<!-- 1. Include the Dedicated Mobile Script --> <script src="https://mlangdon.github.io/ayc-tide-clock/web/ayc-tide-mobile.js" defer></script> <!-- 2. Embed with Custom Config Options (All attributes optional) --> <ayc-tide-mobile show-dial="true" dial-size="250" show-weather="true" show-forecast="true" show-bridges="true" show-table="true" show-wave="true" tide-count="4"> </ayc-tide-mobile> <!-- 3. Or Ultra-Compact Card (Hides dial & forecast for minimal vertical height) --> <ayc-tide-mobile compact="true" tide-count="3"></ayc-tide-mobile>

Mobile Configuration Attributes:

  • compact="true": Ultra-compact mobile mode (hides canvas dial and 3-day forecast).
  • show-dial="true|false": Toggle the analog chronometer dial.
  • dial-size="250": Set the canvas dial pixel size (default 250px, scales with Retina dpr).
  • tide-count="4": Configure number of upcoming high/low events shown (e.g. 3, 4, 6, 8).
  • show-weather="true|false": Toggle Tempest weather station observations.
  • show-forecast="true|false": Toggle 3-day harbor weather forecast strip.
  • show-bridges="true|false": Toggle Sea Bright & Highlands bridge clearances.
  • show-wave="true|false": Toggle the water level sine wave visualizer.
  • theme="ayc_navy": Theme selection (official AYC palette).

Current Application Features

🎨 AYC Official Color Palette Styled using official colors from atlantisyachtclub.org (Ocean Blue #457B9D, Deep Navy #1D3557, Honeydew #F1FAEE, Regatta Red #E63946).
⏱ Marine Tide Chronometer Dial High-resolution anti-aliased canvas dial with live hour markers, flood/ebb sector arcs, blued-steel hand, and AYC burgee insignia.
🌤 Current Weather & 3-Day Forecast Real-time station observations and 3-day daily forecast with direct button link to Tempestwx Station #141221.
🌕 Moon Phase & Tidal Range Indicator Real-time astronomical lunar age, illumination percentage, and Spring/Neap tide current/range prediction.
📐 Bridge Clearances & Headroom Carets Live overhead clearance under Sea Bright (Draw 15.0' MHW) and Highlands (Fixed 65.0' MHW) bridges with directional headroom carets (▲/▼).
🌊 Sea Bright Current Speed Live channel current velocity (knots), direction, and acceleration carets with toggle between NOAA harmonic API and Hydraulic math model.
📅 8-Event Tidal Schedule Table Upcoming 8 consecutive high and low tide predictions synchronized with NOAA Station 8531680 (Sandy Hook / AYC slips).
⚖ Navigational Safety Disclaimer Integrated formal navigational notice reminding mariners to rely on official NOAA charts and Coast Guard aids.

GitHub Pages Deployment Setup

  1. In your repository on GitHub: github.com/mlangdon/ayc-tide-clock
  2. Go to Settings > Pages (in the left sidebar).
  3. Under Build and deployment:
    • Source: Deploy from a branch
    • Branch: main / Folder: / (root)
    • Click Save.
  4. Once published, your script is globally available over HTTPS with CORS support for any client website.
