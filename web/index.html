Live Marine Tide Chronometer & Tempestwx Weather Station 141221

Web Embedding Instructions

You can embed this interactive widget into any standard website (WordPress, Squarespace, Wix, custom HTML, Club portal) using standard HTML tag embedding.

Method 1: Custom Web Component (Recommended)

Include the script from your hosted repository or CDN and drop the custom tag wherever you want the widget to appear:

<!-- 1. Include the AYC Tide Clock Script --> <script src="https://<your-github-username>.github.io/<repo-name>/web/ayc-tide-clock.js" defer></script> <!-- 2. Insert the widget tag anywhere on your webpage --> <ayc-tide-clock></ayc-tide-clock>

Method 2: Standard Iframe Embedding

If your CMS or website host restricts external custom scripts, you can embed the widget inside an iframe:

<iframe src="https://<your-github-username>.github.io/<repo-name>/web/index.html" width="100%" height="720" frameborder="0" style="border: none; border-radius: 8px; max-width: 980px; display: block; margin: 0 auto;" scrolling="no"> </iframe>

Hosting on a Private GitHub Repository

  1. Push the web/ directory (ayc-tide-clock.js and index.html) to your GitHub repository.
  2. Enable GitHub Pages in your repository settings (Settings > Pages > Build and deployment: Deploy from a branch, select main or gh-pages). Note: GitHub Pages can serve public assets even from private repos on GitHub Enterprise/Pro or public repos. Alternatively, host the single standalone ayc-tide-clock.js file on any web host, AWS S3/CloudFront bucket, or Cloudflare Pages.
  3. The client browser will fetch live NOAA tide data and Tempestwx station #141221 observations directly without requiring any server backend.
